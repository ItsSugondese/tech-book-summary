**Internet Engineering Task Force** is an organization responsible for setting rule for internet standards. This includes:

- TCP/IP
- HTTP
- DNS
- Email protocols
- Security protocols

# RFC
**Request for Comments** is documents created by IETF where one or more of the following things are defined:

- Internet protocols
- Standards
- Procedures
- Best practices
- Research ideas

The RFC for OAuth 1.0 is 5849
